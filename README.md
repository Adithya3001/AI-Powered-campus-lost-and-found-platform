# CampusFind AI – AI-Powered Campus Lost and Found Platform

## Sprint 1 – Project Setup and Core Features

### Project Overview

CampusFind AI is an AI-Powered Campus Lost and Found Platform designed to help students and staff report, search, and recover lost items within a college campus.

The platform provides a simple and user-friendly system where users can register, log in, report lost or found items, and search through available reports. The project will later include AI-based matching and image recognition to automatically identify possible matches between lost and found items.

---

## Problem Statement

Students and staff often lose personal belongings such as mobile phones, wallets, ID cards, keys, bags, books, and other valuable items on campus. Traditional lost and found systems usually depend on notice boards, security offices, or word-of-mouth communication, making the process slow and inefficient.

CampusFind AI aims to provide a centralized digital platform that simplifies the lost and found process and, in future sprints, uses Artificial Intelligence to automatically suggest possible matches between lost and found items.

## Expected AI Features

In future development, the system will use Artificial Intelligence to improve the matching process.

The AI system is expected to:

1. Compare lost and found item descriptions.
2. Identify similar keywords and categories.
3. Analyze uploaded item images.
4. Suggest possible matches automatically.
5. Assign a confidence score to potential matches.
6. Notify users when a suitable match is identified.
